계정 연결 확인 (AI 앱 승인과 별도)

                
이 PC의 보안 Agent 앱을 내 ALEPH 계정에 연결합니다. 비밀번호나 API 키를 옮겨 적을 필요가 없습니다. 계정을 연결한 뒤에는 아래에서 AI
                  사용 승인을 따로 진행하세요.

                
    
                  
  1. 「계정 연결 시작」을 누릅니다.
    2. 
                  
  2. 「계정 확인 페이지 열기」로 포털을 열고, 이 화면에 보이는 6자리 확인 번호를 포털에 입력해 확인합니다.
    3. 
                  
  3. 이 화면으로 돌아와 「로그인 확인 완료」를 누릅니다.
    4. 
                  
  4. 계정 연결이 확인되면 AI 앱 승인은 아래 「AI 연결 시작」으로 따로 진행합니다.
    5. 
                

                

                  
                  계정 확인 페이지 열기
                  
                  
                  
                

                

              

              
주소·열쇠를 직접 입력하지 않습니다. 기존 Workbench 로그인 승인 화면에서 이 앱 연결을 승인하면 연결 정보는 이 PC의 앱 서버가 따로 보관합니다.
                연결 뒤에는 Workbench 를 계속 켜 둘 필요가 없습니다. 이 안내는 연결 절차이며 통과·점수·순위 판정이 아닙니다.

              
    
                
  1. 「AI 연결 시작」을 누릅니다.
    2. 
                
  2. 확인 번호를 보고 「승인 페이지 열기」로 Workbench 승인 화면을 엽니다.
    3. 
                
  3. 같은 번호인지 확인하고 승인한 뒤 「승인했으며 연결 확인」을 누릅니다.
    4. 
                
  4. 연결 완료·실패·확인 불가 중 결과를 확인합니다.
    5. 
                
  5. 연결 완료면 「현재 API 연결 점검」으로 모델 응답을 점검합니다.
    6.
