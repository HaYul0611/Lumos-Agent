# 21·22단계 제출 준비 메모 (학생용)

이 문서는 `STUDENT_RUNBOOK.md`의 실행 절차를 대신하지 않습니다. 학생 문서를 같은 단계의 제출 흐름과 연결하기 위한 메모입니다. 실제 포털 화면, 저장소 주소, Git 최상위 경로, 변경 파일, 현재 커밋 40자리 값은 이 작업 공간에서 확인할 수 없습니다. 따라서 실제 명령을 조립하거나 제출을 완료했다고 주장하지 않습니다.

## 먼저 구분할 폴더

- **앱 실행 폴더:** `<프로젝트 폴더>\on-client`. 실행 도구 `tools\start-alekov.ps1`은 이 앱 폴더에서 실행합니다.
- **Git 최상위 폴더:** 시작 틀 안내 기준으로 `on-client`의 한 단계 위인 프로젝트 폴더입니다. 커밋된 원문을 제출하는 도구는 과제 화면이 요구하는 Git 최상위에서 실행해야 합니다.
- `<프로젝트 폴더>`는 본인 PC에서 실제 위치를 확인해 사용합니다. 이 문서의 상대 경로를 임의의 절대 경로로 바꾸거나 추측하지 않습니다.

## 공개 저장소를 사용하는 경우

1. 프로젝트의 기존 변경 사항을 보존하고, 실제로 제출할 커밋과 저장소 주소를 확인합니다.
2. ALEPH 해당 단계 화면이 요구하는 저장소 주소와 40자리 커밋 ID를 직접 입력합니다.
3. 포털에서 저장소·커밋·단계를 다시 확인하고 제출합니다.
4. 원문 전달 완료와 AI 검토 통과는 서로 다른 상태입니다. 서버의 원문 전달 상태와 판정 설명을 따로 확인합니다.

공개 저장소로 바꿀 필요가 있다는 뜻이 아닙니다. 비공개 저장소는 아래의 비공개 원문 전달 절차를 따릅니다.

## 비공개 저장소의 커밋 원문 전달

1. 해당 단계의 과제 화면에서 **「비공개 저장소 원문 준비 방법」**을 펼칩니다.
2. 그 화면의 **「원문 전달 도구 받기」**를 사용합니다. ZIP은 프로젝트 폴더 바깥에 압축 해제하고, JSON 출력용 새 폴더도 프로젝트 바깥에 먼저 만듭니다.
3. 과제 화면에 표시된 `student-source-cli.mjs` 사용법과 옵션을 그대로 확인합니다. 이 문서에는 실제 화면을 볼 수 없어 정확한 CLI 구문·옵션 철자·기본 경로를 재현하지 않습니다.
4. 제출할 프로젝트의 **Git 최상위 폴더**에서 PowerShell을 엽니다. 과제 화면이 제시한 명령에서 도구 파일 경로와 출력 JSON 경로를 본인 PC 위치에 맞게 바꾸고, `--commit` 뒤에는 실제 제출할 40자리 커밋 ID를 지정합니다.
5. 도구는 해당 커밋의 원문을 묶는 용도입니다. 학생 코드를 실행하거나 원문을 업로드하지 않습니다. 생성된 JSON을 같은 단계 화면의 **「비공개 저장소 원문 묶음」**에서 선택합니다.
6. 화면에서 저장소·커밋·단계를 다시 대조한 뒤 제출합니다. 원문 전달만 실패한 경우 기존 접수를 유지하고 **「원문만 다시 보내기」**를 사용합니다. AI 검토의 통과 여부는 별도 서버 상태와 판정 설명에서 확인합니다.

### 명령 작성 전 필요한 확인

다음 정보가 있어야 로컬 PC에 맞는 정확한 명령을 구성할 수 있습니다.

- 과제 화면이 제시한 최신 CLI 명령 원문
- 본인 PC의 프로젝트 Git 최상위 폴더 경로
- 프로젝트 밖에 압축 해제한 도구 파일의 실제 경로
- 프로젝트 밖 JSON 출력 폴더의 실제 경로
- 제출할 커밋의 실제 40자리 ID

이 정보는 여기서 확인하지 않았습니다. 따라서 명령 예시, 저장소 주소, 커밋 ID, 생성된 JSON 경로를 만들지 않았습니다. 사용자는 필요한 경로와 커밋 값을 과제 화면·본인 PC에서 직접 확인한 뒤, 그 화면의 CLI 구문을 따릅니다. Git 명령 실행, 커밋 생성, 업로드, 포털 제출은 이 문서 작성 과정에서 수행하지 않았습니다.

## 변경 보존과 제출 전 확인

- 다른 변경이 커밋 준비 중일 수 있으므로, 본인이 먼저 변경 내용을 확인하고 기존 작업을 보존합니다. 확인할 수 없는 변경은 덮어쓰거나 정리하지 않습니다.
- 학생 문서와 해당 단계 코드를 같은 커밋에 포함하라는 과제 안내를 따릅니다. Git 상태·스테이징·커밋 기록은 이 문서 작성자가 확인하지 않았습니다.
- 커밋 해시는 직접 Git에서 확인하고 과제 화면에 표시된 값과 대조합니다. 이 문서에 해시를 임의로 적지 않습니다.
- 비공개 저장소를 공개로 바꾸지 않습니다. 비밀값·토큰·비밀번호는 코드·설정 문서·제출 메모에 쓰지 않습니다.
- 공식 판정은 제출된 커밋을 기준으로 하며, 로컬 화면 확인이나 원문 전달 완료만으로 단계 통과를 주장하지 않습니다.
